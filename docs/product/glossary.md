# Glosario

| Término | Significado |
| --- | --- |
| Agencia | Cliente del SaaS. Espacio de datos aislado (tenant) con sus usuarios y registros. |
| Usuario | Persona con cuenta. Puede pertenecer a varias agencias mediante membresías. |
| Membresía | Vínculo entre un usuario y una agencia con un rol. Puede revocarse. |
| Rol | Conjunto de permisos. MVP: admin, asesor, lectura. |
| Contacto | Persona o empresa con uno o varios teléfonos y correos. Puede ser comprador, pagador o viajero. |
| Lead | Consulta comercial registrada (formulario, WhatsApp, importación o manual). |
| Oportunidad | Intención concreta de viaje en seguimiento. Un contacto puede tener varias. |
| Embudo | Estados de la oportunidad: nuevo, pendiente de contacto, contactado, en calificación, calificado, en preparación de propuesta, propuesta enviada, negociación, ganado, perdido. |
| Motivo de pérdida | Razón obligatoria al marcar perdida: precio, falta de disponibilidad, cambio de planes, sin respuesta, competencia u otro. |
| Tarea | Acción con responsable, fecha, prioridad y resultado, vinculada a un contacto u oportunidad. |
| Próxima acción | La tarea pendiente más cercana de una oportunidad. |
| Cotización | Propuesta comercial vinculada a una oportunidad. Tiene versiones. |
| Versión de cotización | Fotografía inmutable de ítems, precios, condiciones y cálculo al enviarse. |
| Ítem | Servicio dentro de una cotización: alojamiento, transporte, excursión, seguro, traslado u otro. |
| Coste | Lo que la agencia paga al proveedor. Nunca visible para el cliente. |
| Precio de venta | Lo que paga el cliente por el ítem. |
| Utilidad bruta | Venta neta menos coste comparable. |
| Margen sobre venta | Utilidad dividida por venta neta. |
| Recargo sobre coste | Utilidad dividida por coste. |
| Proveedor | Hotel, operador, aerolínea u otro que presta el servicio. |
| Auditoría | Registro de agencia, actor, fecha, objeto, cambio y motivo. |
| Fase | Bloque del roadmap con una puerta de aceptación (A a E). |
| Puerta | Revisión al final de una fase que decide si se invierte en la siguiente. |
